# 内容工厂最小质量抽检规则

这不是评分系统，也不是复杂质检平台。

这份清单只服务当前项目里最关键的输出链路，目的是：
- 快速发现明显跑偏
- 少做无效 prompt 微调
- 核心改动后能用同一套口径抽检

---

## 一、什么情况下必须抽检

出现下面任一改动时，必须做最小人工抽检：

1. 公众号主写作 skill 改动后
2. second-stage finalization 改动后
3. `post-trimmer` 规则改动后
4. Markdown 导出改动后
5. 发布链路改动后
6. 模型切换后

---

## 二、每次抽检先只看这 5 项

### 1. 字数是否合理
- 是否明显过长
- 是否明显过短
- 是否接近当前目标区间

### 2. 排版是否可发
- 段落是否偏短
- 小标题是否清楚
- 阅读压力是否可接受

### 3. 标题是否跑偏
- 标题方向是否还对
- 是否变得更刺激、更营销化

### 4. AI 味是否变重
- 是否出现模板式开号
- 是否出现“正确但没味道”的句子
- 是否更像系统在交差

### 5. Markdown 结构是否正常
- 标题层级是否正常
- 列表 / 引用 / 分割线是否正常
- `markdownBody` 是否还可编辑、可导出

---

## 三、推荐抽检样本

每次至少准备 1 组固定样本：
- 同一素材
- 同一 `userPrompt`
- 同一 preset

优先做对照：
- 改动前一次
- 改动后一次

如果这轮只改发布 / 导出，也至少要拿同一篇公众号记录做：
- 预览
- 复制
- 发布

---

## 四、公众号生成链路抽检重点

适用于：
- 主写作 skill
- second-stage
- `post-trimmer`
- 模型切换

建议重点看：
- 是否仍像一个人在说话
- 是否还保留口语感
- 是否减少解释型重复
- 是否没有重新变成模板稿
- 标题是否被带偏

---

## 五、Markdown 导出抽检重点

适用于：
- `wechat-markdown-export.ts`
- 预览 HTML
- 发布 HTML
- 复制微信格式

建议重点看：
- 标题层级是否正常
- 段落行距是否可用
- 引用样式是否清楚
- 列表样式是否清楚
- 复制结果与发布结果是否大致一致

---

## 六、发布链路抽检重点

适用于：
- 发布 mapper
- 发布 service
- publish snapshot

建议重点看：
- 新记录是否优先从 `markdownBody` 发布
- 旧记录是否还能从 `blocks` 兜底发布
- 封面图 / 正文头图是否还正常
- 发布入口是否不报错

---

## 七、抽检结论怎么写

每次抽检建议直接写 5 行结论：

- 字数：通过 / 不通过
- 排版：通过 / 不通过
- 标题：通过 / 不通过
- AI 味：通过 / 不通过
- Markdown 结构：通过 / 不通过

如果某项不通过，再补一句“具体跑偏点”。

---

## 八、这份清单的定位

这份规则只做一件事：
- 让每次关键链路改完后，都能用同一套最小口径快速抽检

先做到“稳定抽检”，再考虑更复杂的自动评分。
